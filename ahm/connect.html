Choose an Agent integration method

This page collects only the "integration type" and no credentials. Once the Connector is available, probes run locally in your own environment; AHM receives only low-sensitivity summaries.

⏳ Local Connector in development (planned) — This page is a pre-launch preview; only the planned download and run steps are shown here, and the Connector is not yet available for download. The real probes (Evidence-lite / Deep Local) are implemented separately; this page does not present them as available.

Four integration methods

These are the planned integration methods for after the Connector is released; none are available yet.

① OpenAI-compatible HTTP

User action: configure a local endpoint; provide credentials via environment variables.
Evidence boundary: the Connector calls locally on your machine; only summaries are output, and raw conversations and credentials never leave your machine.

② Local Agent / CLI

User action: specify a local command or adapter.
Evidence boundary: a fixed allowlist is required; arbitrary remote commands are not accepted.

③ Pre-redacted samples

User action: upload samples you have already redacted yourself.
Evidence boundary: labelled self_reported; not equivalent to real probe results.

④ No integration

User action: complete the questionnaire only.
Evidence boundary: generates triage candidates only; no diagnostic conclusion is produced.

Connector planned fields

A future Connector is planned to generate and return: checkup_id (a unique identifier for one checkup), evidence_level (limited_probe / deep_local), and completed_probe_count / requested_probe_count (number of completed probes). The page displays only these low-sensitivity summary fields and does not accept raw logs.
Security boundaries
  • The browser does not store or upload API keys — credentials live only in your local environment variables;
  • The Connector calls your own Agent on your machine and redacts data locally;
  • No raw logs, prompts, credentials, or full conversations are uploaded;
  • AHM does not execute your Agents, does not expose a public HTTP endpoint, and is not connected to billing or production operations;
  • Diagnostic summaries and contact details are submitted separately.
