DIRECTION

From "like a person" to "always the same being."

Most digital personas exist only within a single conversation. Once the session ends, relationships, commitments, and shared history reset. DLLM explores digital intelligence on a longer timescale: one that retains context and knows which memories it may use and how to explain its own changes.

This direction builds on Nexus's long-term memory capability, but does not equate "remembering more" with "being more life-like." Identity governance, user consent, and exit mechanisms are part of the product definition too.

01

Identity continuity

Studies stable identity expression across sessions and stages, keeping personas from drifting unpredictably over long-term interaction.

02

Relational memory

Distinguishes facts, shared experiences, and relationship state, so the source of a memory and the boundaries of its use can be understood.

03

Revocable boundaries

Treats consent, forgetting, and exit as baseline constraints, not settings to be added after the product is finished.

CURRENT STATUS / DEVELOPING

DLLM's first validation release is published and all controlled experiments have passed; work on the model family and memory injection is underway, while the runtime, remote deployment, and commercialization are not yet complete.
