Nexus: A local memory foundation that helps Agents remember, explain, and support regression testing

Nexus is not a single finished product, but a product system built around "long-term memory" — from free, open-source baseline capabilities, to a ready-to-use platform plugin, to an enterprise-backed commercial core. Below we first clarify what the three tiers are and who they are for, then why they may be worth your consideration.

Three tiers, choose what you need

One memory core, three delivery forms. Higher tiers offer stronger guarantees and less to manage; lower tiers offer more freedom and less weight. You can start with the free layer and move up as your needs grow.

② Integration · Platform plugin

dsh-nexus-memory

DSH plugin · v0.3.1 released

A memory plugin for the DSH desktop agent platform, built on Nexus, bringing long-term memory directly into your Agent workflow.

  • A "Memory" button in the title bar: extracts memory from the last 10 turns, with lightweight rules by default at zero token cost

Why the commercial edition, and how it differs from ordinary memory software

Most memory solutions on the market stop at "putting things into a vector store". What makes Nexus Commercial different is that it treats memory as an asset that needs to be governed, not as one-off context stitching.

Is it usable in real conditions

In plain terms: the foundation can reliably "remember and find back", but "finding material" is not the same as "always answering correctly". Below is our honest assessment of whether it is ready to deploy.

✓ Ready to use

Local-first, auditable, zero-failure regressions, zero crashes under controlled capacity — well suited to small teams that want to keep memory on their own machines, without worrying about data leaving their boundary or being locked in.

✓ Retrieval layer is trustworthy

Session recall sits in the upper range of the public literature; memory augmentation clearly beats "no memory" across several slices and is already close to the "full context" effect.

△ Still being refined

Absolute answer accuracy still needs work — we position it as a "memory and evidence layer", not a "fully automatic answer machine". That is exactly why we offer a diagnostic methodology rather than pushing a black-box product.

△ Cost needs attention

4B responds in about 1.5–2.3 seconds and is usable; 8B has higher latency on some slices (about 28 seconds) and is still being optimized. We recommend choosing a model per scenario rather than defaulting to larger parameter counts.
