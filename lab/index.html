OPEN ARTIFACTS

Open code and research packages

Two projects you can obtain directly: code, configuration and research records are public, for inspection and reproduction. Neither includes model weights.

01 · INTENT ROUTING / v0.3.0

DLM-9B Intent-Routing Validation Prototype

On a single local 12GB GPU, three independent public models - text, image and video - are connected into a reproducible, auditable scheduling chain. Bounded conclusions are drawn on the role of the memory mechanism and the structural conditions for a unified model.

Related direction: multi-backend scheduling and capability routing · Code Apache-2.0; third-party model licences belong to their respective upstream projects

GitHub · Code and experiment log ↗ Hugging Face · Project page ↗
02 · COGNITIVE RUNTIME / v0.1.0

Cognitive Learning Lab

A frozen proposal model paired with external memory answers bounded decisions: the model only proposes, and only validated memory can authorise an answer and a write-back, remaining effective after a restart. Output is layered with evidence and is traceable and reproducible.

Related direction: cognitive learning experiment line · Code Apache-2.0; no bundled weights, no claim of autonomous learning or production readiness

A

TRACK A · MEMORY

Nexus memory research line

Keeping external memory semantically reliable over time: mechanisms, protocols and measurement methods come first; implementation details are not published.

A1

White paper on the external memory mechanism In preparation

The public outline of the six-stage mechanism - extract, store, retrieve, inject, feed back, maintain - together with governance design for anchors, rules, conflict resolution and lifecycle.

A2

Memory state transition experiments Exploratory

How a single memory moves through states - candidate, review, injection, refusal and recovery - and how the same question is answered under different memory conditions.

A3

Semantic fidelity and retrieval noise Exploratory

Extending the measurement line of the preprint: how retrieval noise affects answer-level semantic drift, and how to define whether memory helped or hurt.

B

TRACK B · COGNITIVE LEARNING

DLLM-CL cognitive learning experiment line

Controlled experiments explore the real boundaries of external memory and learning capability - negative results are published alongside positive ones.

B1

Effect of memory on coverage and accuracy Report in preparation

In controlled tasks, external memory improved task coverage and selective accuracy for some cases; conclusions stay within the controlled task scope.

B2

Cross-template transfer of typed memory Exploratory

How well typed attributes transfer between controlled task families, and control of evidence leakage.

B3

Retention and recovery of persistent memory Exploratory

Memory retention, contamination isolation and recovery within the test window; long-term decay has not been evaluated and is noted as such in the report.

B4

Tool acquisition and evidence promotion Exploratory

An auditable chain - acquire, validate and promote, replay without duplicate calls - with every step traceable.

B5

fail-closed evidence gate Exploratory

Evidence that is wrong, conflicting or missing proof should be blocked before output - the system would rather refuse than emit unsound results.

B6

Negative results series Exploratory

More evidence is not always better; evidence compression can lose usefulness; irrelevant memory can hurt selection quality.

B7

Learning boundaries Exploratory

A change in parameters does not mean improved behaviour, still less cross-task generalisation - the boundary itself deserves a methodology paper.

C

TRACK C · SYSTEM DESIGN

System design line

Public architecture design and methodology: set out the thinking first, then discuss practical application.

C1

Modular cognitive runtime and evidence contracts Design report

A modular cognitive network independent of model form: boundary design for modules, tasks, state and evidence contracts; and why static validation cannot replace runtime admission.

C2

Reproducible evaluation protocol for local small models Design report

An evaluation method with a fixed task set, output contracts, behavioural and resource metrics, and controlled comparisons across quantisation levels.

C3

Cross-device architecture with small-core / large-core cooperation Design report

Local small core, cloud large core, capability routing and fail-closed governance: a local-first agent foundation that works offline, degrades gracefully and stays verifiable.

C4

Multimodal cognitive network design Design report

Modality adapters, shared task contracts and workflow orchestration for text, image and audio; no claim of cross-modal generalisation before unified experiments are complete.
